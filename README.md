# 2026-GP1-Group8 — loadout

Combined repository for the loadout project.

## Structure

```
.
├── backend/   Node.js + Express API, with a Python recommender service
└── flutter/   Flutter mobile/web client
```

## Backend

Node.js / Express API.

```bash
cd backend
npm install
npm start
```

Required local files (not committed):
- `backend/.env` — environment variables
- `backend/serviceAccountKey.json` — Firebase Admin SDK credentials
- `backend/recommender/.env` — recommender service env

### Recommender (Python)

```bash
cd backend/recommender
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload


## Flutter

```bash
cd flutter
flutter pub get
flutter run
```

Required local files (not committed):
- `flutter/lib/firebase_options.dart` — generated by `flutterfire configure`
- `flutter/ios/Runner/GoogleService-Info.plist`
- `flutter/android/app/google-services.json`
